# Измерение скорости загрузки

Скрипт для Node.js 22 и новее измеряет скорость загрузки файла по HTTP или HTTPS. Для запуска достаточно самого Node.js.

## Запуск

Склонируйте репозиторий и перейдите в его папку.

```sh
git clone https://github.com/Serezjjja/download-speed-cli.git
cd download-speed-cli
```

Передайте скрипту URL файла. Например, эта команда скачает логотип Node.js десять раз.

```sh
node download-speed.mjs "https://nodejs.org/static/logos/nodejsLight.svg"
```

## Как работает

Скрипт делает 10 GET-запросов. Каждый следующий запрос начинается после полного чтения предыдущего ответа. Укажите конечный URL файла. При перенаправлении, другом статусе вне диапазона 2xx, сетевой ошибке или бездействии сокета в течение 30 секунд скрипт завершится с кодом 1.

После десятого ответа скрипт выводит три показателя.

1. **Среднее время запроса** в миллисекундах, от начала GET до получения последнего байта тела ответа.
2. **Общий объём** в байтах. Учитываются только тела ответов. Если сервер применил сжатие, скрипт считает байты в сжатом виде.
3. **Скорость скачивания** в мебибайтах в секунду (МиБ/с). Скрипт делит общий объём в байтах на 1 048 576 и на суммарное время десяти запросов в секундах.
