# Измерение скорости загрузки

Скрипт 10 раз скачивает файл по HTTP или HTTPS и выводит среднее время запроса, общий объём и скорость. Для запуска достаточно Node.js 22 или новее, включая Node.js 26 LTS.

## Запуск

Склонируйте репозиторий и запустите скрипт. Последний аргумент — адрес файла. В примере это логотип Node.js.

```sh
git clone https://github.com/Serezjjja/download-speed-cli.git
cd download-speed-cli
node download-speed.mjs "https://nodejs.org/static/logos/nodejsLight.svg"
```

## Как работает

Время каждого GET измеряется от начала запроса до конца чтения тела. Цикл `for await...of` складывает размеры блоков по мере получения. Даже большой файл можно измерить без загрузки в память целиком. Следующий запрос начинается после завершения предыдущего.

- **Среднее время** = сумма длительностей десяти запросов в миллисекундах / 10.
- **Объём** = сумма байтов тел десяти ответов без HTTP-заголовков. При сжатии учитывается размер сжатого тела.
- **Скорость в МиБ/с** = общий объём в байтах / 1 048 576 / сумма длительностей запросов в секундах.

Укажите конечный URL. Если сервер вернёт статус вне диапазона 2xx, соединение оборвётся или сокет будет бездействовать 30 секунд, скрипт остановится с кодом 1.
